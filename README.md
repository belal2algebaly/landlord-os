# Landlord OS

A zero-dependency web MVP for small landlords managing 1–10 rental units.

## Features
- Portfolio overview
- Properties
- Tenants
- Rent tracking
- Expenses
- Alerts
- Local persistence via browser localStorage
- Dynamic payment and lease status logic
- Data export and validation improvements

## Deploy
Static site. No build command is required on Vercel.
